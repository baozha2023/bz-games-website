你的游戏，你的规则

BZ-Games 是一个本地优先的 Windows 游戏平台。导入、管理、市场下载、房间联机、成就统计与个性化资料都在一个客户端里完成。

下载 Windows 版 GitHub

为什么选择 BZ-Games

专为 Windows 打造的本地游戏管理、市场下载与联机体验

📂

开放式游戏库

支持导入任意符合规范的本地游戏，自动识别版本、封面与元数据，拖拽即玩。

🔌

本地优先数据

配置、游戏记录、统计、成就与 BZ 币都优先存储在本机，配置文件加密保存，无需注册云端账号。

🎮

统一联机大厅

内置创建、加入、准备、开始、聊天、踢人、解散与断线处理，游戏只需接入本地 Game API。

🌐

多入口联机

局域网发现、用户自备 frp 直连、官方中继短地址三种入口并存，按场景自由切换。

🏪

游戏市场

浏览多来源社区游戏，下载任务支持进度、暂停、恢复、取消与悬浮球提醒，安装自动校验和导入。

🏆

成长与个性化

成就、签到、BZ 币、游玩统计、日历热力图、头像框和昵称特效，让本地资料也有成长感。
